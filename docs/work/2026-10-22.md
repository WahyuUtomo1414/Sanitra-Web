# Catatan Kerja

## 22 Oktober 2026 (WIB)

1. **Bug fix — `protected static ?string $heading` di ChartWidget:** Tiga widget chart yang dibuat kemarin (`MarketingConversionChartWidget`, `FinanceRevenueChartWidget`, `FinanceInvoiceStatusChartWidget`) mendeklarasikan `$heading` sebagai `static`, sedangkan di Filament 5 `ChartWidget::$heading` adalah non-static property. PHP fatal error: *"Cannot redeclare non static ... as static"*. Diperbaiki dengan mengubah `protected static ?string $heading` → `protected ?string $heading` di ketiga file tersebut.

2. **Reusable email template (Sanitra corporate design):** Publish vendor mail views (`php artisan vendor:publish --tag=laravel-mail`) lalu kustomisasi tiga file:
   - `resources/views/vendor/mail/html/themes/default.css` — warna primary dari `#18181b` (hitam Laravel default) ke `#1e3a8a` (navy Sanitra), background `#f0f4ff`, border/panel `#bfdbfe`, semua tombol dan link ikut navy.
   - `resources/views/vendor/mail/html/header.blade.php` — header bar navy `#1e3a8a` dengan nama "PT Sanitra Sapta Utama" putih + label "Sistem Notifikasi" di kanan.
   - `resources/views/vendor/mail/html/footer.blade.php` — footer dengan nama perusahaan, garis navy, dan disclaimer "Email ini dikirim otomatis oleh sistem."
   
   Dengan pendekatan ini semua notifikasi yang pakai `MailMessage` otomatis dapat desain corporate yang konsisten tanpa perlu Blade view per-notifikasi.
