# Catatan Kerja

## 14 Oktober 2026 (WIB)

1. Memperbaiki bug tampilan input uang yang menampilkan nilai 12 triliun (bukan 12 juta). Akar masalah:
   - `->stripCharacters('.')` mendaftarkan `StripCharactersStateCast` yang berjalan sebelum `afterStateHydrated`. Cast ini menghapus **semua** titik dari value DB `'12000000.000000'` → `'12000000000000'` (12 triliun).
   - `->numeric()` mendaftarkan `NumberStateCast` yang memanggil `floatval('12.000.000')` = `12.0` (PHP berhenti di titik kedua), merusak input berformat Indonesia.
   - Solusi: hapus `->stripCharacters('.')`, `->numeric()`, dan `->formatStateUsing()` dari `MoneyInput::make()`.

2. Memperbaiki regresi save button tidak bereaksi setelah perbaikan nomor 1. Akar masalah: `afterStateHydrated` menyimpan state sebagai angka mentah `'12000000'`, Alpine mask memformatnya menjadi `'12.000.000'` dan men-dispatch `input` event, `wire:model.live` mengirim `'12.000.000'` ke server, `afterStateHydrated` mengonversinya balik ke `'12000000'`, Alpine mask memformat ulang — loop tak berakhir → form tidak pernah settle → save button tidak bisa difire.

   Solusi akhir di `MoneyInput::make()`:
   - `afterStateHydrated` kini menyimpan state dalam format display (`'12.000.000'`) sehingga Alpine mask tidak perlu mengubah apapun → tidak ada loop.
   - `dehydrateStateUsing` membersihkan titik sebelum data dikirim ke service sehingga service menerima `'12000000'` dan lolos validasi `numeric`.
