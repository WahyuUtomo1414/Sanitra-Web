# Catatan Kerja

## 31 Oktober 2026 (WIB)

1. **Analisis role & permission dari dump server (`docs/permision.md`):** Dump memuat 221 permission, semuanya ter-assign ke `super_admin`. Role Marketing, Finance, Teknis punya nol permission dan nol user. Mapping izin per role operasional belum pernah dilakukan di server.

2. **Matriks permission di `RoleSeeder` + custom permission di Shield config:** `RoleSeeder` sekarang menerapkan matriks penuh per role via `syncPermissions()`. Konstanta `ROLE_PERMISSIONS` memuat izin Marketing (27), Finance (21), dan Teknis (9). `super_admin` disinkronkan dengan semua permission `web` karena `super_admin.define_via_gate = false`. Tujuh permission bisnis awal (`Send/Approve/Revise/Reject:TransSalesQuotationHd`, `Void:TransSalesInvoiceHd`, `Confirm/Reject:TransSalesPayment`) didaftarkan di `config/filament-shield.php` kunci `custom_permissions`.

3. **Pengamanan action bisnis di Filament:** Tambah guard `Gate::authorize(...)` pada `visible()` **dan** closure `action()` untuk tombol Kirim/Setujui/Revisi/Tolak Quotation, Batalkan Invoice, serta Konfirmasi/Tolak Payment (termasuk relation manager di Invoice). Halaman custom `CreateOrderInvoice` memeriksa `Create:TransSalesInvoiceHd` pada `mount()` dan `create()`. `canEdit`/`canDelete` di `TransSalesQuotationHdResource` juga menambahkan guard role Marketing/super admin.

4. **Rapihin pattern otorisasi — hardcoded role → permission:**
   - Buat enum `App\Enums\RoleName` (SuperAdmin, Marketing, Finance, Teknis) untuk menghilangkan string literal `'super_admin'`/`'Marketing'`/dst. di seeder dan guard.
   - Dua custom permission tambahan di Shield config: `Close:TransSalesOrderHd` dan `Access:ImportMasterData`. Keduanya hanya diberikan ke `super_admin` lewat konstanta baru `SUPER_ADMIN_ONLY_PERMISSIONS` di `RoleSeeder` (dibuat via `firstOrCreate` sebelum sync super admin).
   - `ViewTransSalesOrderHd::canClose()`: `hasRole('super_admin')` → `Gate::allows('Close:TransSalesOrderHd')`.
   - `ImportMasterData::canAccess()` + `import()`: `hasRole('super_admin')` → `can('Access:ImportMasterData')`.
   - `routes/web.php` template download: `hasRole('super_admin')` → `can('Access:ImportMasterData')`.
   - `UserSeeder`, `RoleSeeder`, `ViewTransSalesQuotationHd`, `TransSalesQuotationHdResource` memakai `RoleName::*->value` menggantikan string literal.

7. **Urutan deploy ke server:**
   ```sh
   git pull
   php artisan config:clear && php artisan route:clear
   php artisan shield:generate --all --option=permissions --panel=dashboard --no-interaction  # opsional, kalau ada resource/widget baru

   ```
